SOBRE ESTE PROJETO

PS4 WebHost é um projeto independente de interface e organização. O código de exploit, offsets, binários e payloads devem manter os créditos e licenças dos respectivos desenvolvedores. GitHub Pages hospeda arquivos estáticos; não fornece servidor de execução no console.

Próxima etapa: integrar uma cadeia pública verificada para 13.52, conferir licenças e testar no PS4 Slim antes de publicar como host operacional.

Use somente em console próprio e mantenha cópias de segurança. Exploits podem falhar, travar o navegador ou reiniciar o console. O jailbreak não é persistente após reinicialização completa.
